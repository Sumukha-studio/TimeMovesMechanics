# TimeMovesMechanics

Unity mechanics exploration project where time moves when you move (inspired by SUPERHOT mechanics).

## Project Details
- **Unity Version:** `6000.3.24f1` (Unity 6)
- **Render Pipeline:** Universal Render Pipeline (URP)

## Getting Started

### Prerequisites
- **Git** with **Git LFS** installed:
  ```bash
  git lfs install
  ```
- **Unity Hub** and **Unity 6 (6000.3.24f1)**

### Cloning the Repository
When cloning this repository, make sure Git LFS is installed so that binary assets (textures, audio, 3D models) download properly:
```bash
git clone <repository-url>
cd TimeMovesMechanics
git lfs pull
```
